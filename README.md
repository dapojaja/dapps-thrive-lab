# AI Solutions & Automation Portfolio Website

A clean, premium, business-focused AI portfolio website showcasing capabilities, automated workflows, digital product developments, and proof of work from the Attention Factory AI Fellowship.

---

## 🚀 How to View Locally

This is a traditional static website built with **Plain HTML, Vanilla JavaScript, and Tailwind CSS v4**. 

No build step or server environment is required. You can run it locally in any of the following ways:

### Option 1: Direct File Open
Double-click `index.html` in your file explorer to open it directly in your web browser.

### Option 2: Local HTTP Server (Recommended)
If you have Python installed, you can start a simple server from the project directory:
```bash
python -m http-server 8000
```
Then visit [http://localhost:8000](http://localhost:8000) in your web browser.

---

## 🛠️ Tech Stack & Libraries

*   **HTML5**: Structured semantic markup.
*   **Tailwind CSS v4 (Browser CDN)**: Modern styling utilities and spacing tokens.
*   **Vanilla JavaScript (`app.js`)**: Dynamic data injection, category filtering, detailed project modals, responsive navbar drawer, and contact form handling.
*   **style.css**: Custom overrides for typography, smooth scrolling padding, and modern custom scrollbar aesthetics.
*   **Lucide Icons**: Crisp, uniform, business-oriented vector iconography.
*   **Google Fonts**: *Plus Jakarta Sans* (for corporate headings) and *Inter* (for highly legible body text).
